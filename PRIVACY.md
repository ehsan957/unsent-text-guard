# Privacy Policy: Unsent Text Guard

Unsent Text Guard does not collect, store or transmit any personal data.

- **Your text:** The extension runs on web pages so it can notice when you type into a text box. It only compares how much you typed with what the box contained before. The text stays in the page's memory, is never saved, and is never sent anywhere. Password fields are ignored completely.
- **Settings:** Only two settings are saved, using your browser's own extension storage: the minimum number of typed characters, and the list of websites where you turned the guard off. If browser sync is turned on, your browser may sync these settings between your devices.
- **Network:** The extension makes no network requests.
- **Third parties:** No data is sold or shared with anyone.
